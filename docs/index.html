05 / IDENTITY IS A POLICY CHOICE
Know what the
baseline forgets.
Existing identity semantics are preserved: SHA-256 binds rule and normalized path to either a material digest or message and redacted excerpt. Line and severity are not bound. A severity increase can therefore remain suppressed. Slashes and runs of whitespace normalize, so distinct filesystem paths can share an identity. This inspector exposes those aliases; it does not silently migrate baselines.
A digest is not encryption or anonymization. Low-entropy contact data and paths may be guessable. Keep real baseline files and scan witnesses private. A baseline records a choice to suppress, not a claim that a finding is safe.
Native fixes redact full lines before excerpt truncation, redact metadata excerpts while binding rotations privately, retain all sensitive matches on a line, count successfully read files, and return exit 2 on incomplete scans. Incomplete scans cannot write a new baseline. Baseline JSON rejects duplicate keys, invalid fingerprints and invalid encoding. These corrections do not add new detection patterns or establish detection effectiveness.
